# Tic-Tac-Toe Game

A simple two-player Tic-Tac-Toe game built with Python.

Players take turns choosing positions from 1 to 9. The game prevents players from selecting an occupied position and checks for horizontal, vertical, and diagonal wins. It also detects when the game ends in a draw.

## What I Practiced

* Functions and parameters
* `while` loops
* `if`, `elif`, and `else`
* User input
* Input validation
* Updating list values
* Checking winning combinations
* Detecting a draw
* Using `break` to stop loops
* Refactoring repeated code into reusable functions

## How to Run

Run the Python file and follow the instructions in the terminal.

```bash
python tic_tac_toe.py
```
